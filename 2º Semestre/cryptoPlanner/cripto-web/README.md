# Cripto Planner - Front

Front-end pronto do exercício **Cripto Planner** (Spring REST Client).

## Como rodar

```bash
npm install
npm run dev
```

O app espera um back-end Spring rodando em `http://localhost:8080` com o endpoint:

```
GET /api/planner?activity={activity}
```

retornando `{ "result": "..." }`.

Veja o enunciado completo do exercício para os requisitos do back-end.
