# 1º Semestre

Projetos desenvolvidos durante o primeiro semestre da disciplina de Java Advanced na FIAP.

---

## Projetos

### ValidacaoPersonagem
API REST desenvolvida em Spring Boot com Maven e banco de dados H2 em memória. O projeto consiste em um sistema de criação e validação de personagens de jogo, oferecendo um CRUD completo para gerenciar os personagens, com validação dos atributos de cada um via Bean Validation.

### Cervejaria
API REST desenvolvida em Spring Boot com Maven e banco de dados H2 em memória. O projeto oferece um CRUD completo para gerenciamento de estilos e cervejarias, com implementação de cache para otimização das consultas, documentação interativa via Swagger/OpenAPI e recursos de observabilidade para monitoramento da aplicação.

### Games
API REST desenvolvida em Spring Boot com Maven e banco de dados H2 em memória. O projeto implementa um sistema de gerenciamento de jogos utilizando Spring HATEOAS para retornar hypermedia links em cada resposta, paginação nas listagens e filtros por gênero e plataforma. Possui integração com o front-end [GameFinder Web](https://github.com/joaocarloslima/gamefinder-web).
